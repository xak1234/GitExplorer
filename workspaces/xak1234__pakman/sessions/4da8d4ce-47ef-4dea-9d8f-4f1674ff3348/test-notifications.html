📋 How It Works

  • • Real-time monitoring: The system continuously monitors Firebase for new multiplayer games
  • • Host creation detection: When someone creates a new game, a single ping notification is played
  • • Player join detection: When someone joins an existing game, a double ping notification is played
  • • Smart filtering: Only notifies about games created within the last 10 seconds to avoid spam on page load
  • • Customizable settings: Volume control, individual notification toggles, and master enable/disable
  • • Persistent settings: All settings are saved to localStorage and persist between sessions
